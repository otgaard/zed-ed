Zed Player — Embed Smoke Test

Three <zed-player> instances on one static page. No bundler, no framework — just a single ES module load.

A. Hero mode

Autoplays muted, loops, no UI chrome. Full-width 16:9. The bundle is fetched the first time the element scrolls into view; scrolling away pauses the engine.

<zed-player mode="hero" autoplay muted loop src="demo.zedp"></zed-player>

A2. Live & interactive, no UI

Use mode="minimal" with autoplay for a shader that runs live the moment it's visible — no toolbar, no controls, just the canvas. Pointer events go through to the shader, so it stays interactive. Add muted when the demo has audio (browser autoplay policy requires muted for headless start).

<zed-player mode="minimal" autoplay loop muted src="demo.zedp"></zed-player>
